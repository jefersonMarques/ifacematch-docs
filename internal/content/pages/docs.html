Integração com iFaceMatch

Da primeira chamada ao resultado de uma verificação facial. API no backend, câmera no navegador e dados biométricos processados na instalação Customer Hosted.

Como funciona

A aplicação do cliente solicita uma verificação pelo backend. O iFaceMatch devolve uma URL temporária para a captura no SDK Web; depois o backend consulta o resultado autorizado no Server.

API RESTEndpoints verificados de prova de vida, cadastro e comparação facial.SDK WebToken efêmero, câmera e fluxo hospedado de verificação.Notas de versãoDiferenças entre pacote, Server, Console e SDK.AtualizaçõesAssinatura, preflight, backup e rollback.
Processamento independente

A API facial é hospedada no ambiente autorizado do cliente. O Portal controla licenciamento e distribuição; não recebe imagens ou embeddings biométricos por padrão.

Início rápido

O exemplo abaixo cria uma prova de vida independente, sem cadastrar rosto ou pedir identificador de pessoa. Execute-o apenas no backend da aplicação, com uma credencial válida e seu domínio HTTPS.

Shell · chamada no backend
curl --request POST \
  "$IFACEMATCH_API_ORIGIN/v1/liveness/checks" \
  --header "Authorization: Bearer $IFACEMATCH_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{}'

A resposta de criação contém um identificador da checagem e uma verificationUrl temporária. Entregue ao navegador somente essa URL e consulte o resultado pelo seu backend.

JavaScript · página da sua aplicação
const response = await fetch("/api/identity/start", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    flow: "liveness"
  })
});

if (!response.ok) {
  throw new Error("Unable to start identity check");
}

const { verificationUrl } = await response.json();
window.location.assign(verificationUrl);
Rota de exemplo

/api/identity/start é uma rota que você implementa no backend da sua empresa; não é um endpoint nativo do iFaceMatch. Consulte o exemplo real em Go e JavaScript.

Credenciais e autenticação

Use uma chave de aplicação emitida pelo Console da instalação. A chave pertence ao servidor da sua empresa: não deve ser incluída no JavaScript, HTML, SDK, URL, arquivo público, sistema de logs ou ferramentas de analytics.

Shell · exemplo Go local
export IFACEMATCH_EXAMPLE_API_ORIGIN="https://face.example.com"
export IFACEMATCH_EXAMPLE_API_KEY_FILE="/run/secrets/ifacematch-app.key"

go run example-backend.go

O exemplo lê a chave de um arquivo privado com permissões 0600. O browser recebe apenas um token temporário associado à operação.
