SDK Web e captura facial

O SDK conduz a captura e a prova de vida. Sua aplicação controla a sessão no backend e recebe do iFaceMatch um endereço temporário seguro para o navegador.

Divisão de responsabilidades

ComponenteResponsabilidade
Backend do integradorGuarda a chave da aplicação, emite operações e consulta decisões.
Navegador e SDK WebSolicita câmera e executa a jornada de captura pelo endereço temporário.
iFaceMatch ServerAplica autorizações, biometria 1:1, liveness e emite resultados.

Iniciar captura no navegador

O backend deve validar a chamada do usuário, iniciar uma operação no Server e devolver somente a verificationUrl emitida.

JavaScript · frontend da aplicação
async function startVerification(subjectId) {
  const response = await fetch("/api/identity/start", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      flow: "verify",
      subjectId
    })
  });

  if (!response.ok) {
    throw new Error("Unable to start verification");
  }

  const result = await response.json();
  window.location.assign(result.verificationUrl);
}

O exemplo utiliza uma rota própria do integrador. O pacote instalado serve a página /verify.html e os arquivos versionados do SDK no mesmo domínio da API.

Consultar o resultado

A conclusão visual do fluxo no navegador não equivale à aprovação biométrica. Consulte GET /v1/verifications/{checkId} pelo backend e aplique a decisão fornecida pelo Server.

Não colocar credenciais no SDK

Nunca passe a chave da aplicação como parâmetro de URL, variável global, localStorage ou cabeçalho de requisição originada pelo navegador.
