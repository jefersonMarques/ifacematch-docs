# iFaceMatch Docs

Documentação pública do iFaceMatch Customer Hosted.

Este repositório hospeda **somente a documentação técnica** em `docs.ifacematch.com`. O Server biométrico, o Console, o Portal e a Central permanecem em seus próprios repositórios e serviços.

A implementação do serviço Go com `templ`, HTMX, OpenAPI e GitHub Releases será proposta em uma branch de desenvolvimento e revisada antes da publicação. Nenhum segredo ou dado biométrico deve ser armazenado neste repositório público.
